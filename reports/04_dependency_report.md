### 候选映射冲突（不是真实先修自环）

```json
[
  {
    "external_topic": "cnm_208",
    "external_prerequisite": "cnm_088",
    "internal_id": 10,
    "strength": "hard"
  }
]
```

例如 `cnm_208 → cnm_088` 因两个外部节点都被候选映射到内部 `10`，形成**候选映射冲突**；它不代表外部原始先修关系存在自环。排除高风险候选后该冲突消失。
