# 学习分析（管理员端）

面向超级管理员与学科 `manager`，不创建学生账号。

## 使用

1. 侧边栏进入「学习分析」，选择学科。
2. 「学生档案」新增学生（姓名、年级）。
3. 「错题与记录」选择学生，手动登记答题结果；或使用「批量导入」。
4. 「批量导入」支持下载 Excel 模板、上传 `.xlsx/.csv` 预览后确认；也可用自然语言让 AI 解析为候选，确认后才写入。
5. 「推荐 / 四阶段」生成推荐（默认仅已发布题；可勾选未发布题），确认后创建练习会话。
6. 「掌握度与报告」查看知识点/题型掌握、错题、复习计划与单学生报告。
7. 「规则配置」超级管理员可调整部分正确权重；间隔复习规则可通过 API 配置。

## 规则

- 每次答题独立记录；错题按学生+题目汇总错误/部分正确次数与最近错误时间。
- 部分正确使用可配置权重；样本不足显示“未评估”。
- 推荐使用确定性规则（错题、薄弱知识点、先修、题型、难度、去重），不调用 AI。
- 删除学生会级联删除该学生在本学科的全部学习数据，操作前二次确认。
